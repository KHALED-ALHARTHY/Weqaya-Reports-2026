# Weqaya Reports 2026 — تقارير برامج وقاية

واجهة عربية لإدخال النتائج ولوحة متابعة مع تحرير شروح التقرير قبل الطباعة وتصدير Excel وPowerPoint. يحافظ الموقع على شعار وقاية وألوانه. المستودع يحتوي المصدر ودليل المنشآت فقط؛ لا يحتوي بيانات المستخدم أو ملفات النتائج أو مفاتيح الدخول.

## الاستخدام

اختر سنة الإدخال، ثم فترة العرض والبرنامج في قسم استيراد Excel، وحدد هل الأصفار نتائج فعلية أم خلايا غير مدخلة. اختيار ملف Tracker بصيغة XLSX (حتى 12 MB) يبدأ التحليل مباشرة ويظهر زر تنزيل PowerPoint عند اكتماله. راجع المعاينة قبل الضغط على حفظ النتائج.

نطاق العرض يشمل Q1/Q2/Q3/Q4 والنصفين H1/H2 والسنة كاملة أو أرباعًا مختارة. إعداد العرض لا يقيّد استيراد بقية الفترات؛ الحفظ يحدّث جميع القياسات المطابقة في الملف للسنة المختارة. العرض الجديد يستند إلى الملف، وتقارير لوحة المتابعة إلى البيانات المحفوظة. يمكن تحرير نصوص عرض Python وجداوله ورسومه في PowerPoint قبل اعتماد التقرير.

## الوكلاء الخمسة

`report_generator.py` يحتوي DataExtractorAgent وAnalysisAgent وSlidePlannerAgent وPptxGeneratorAgent وInfectionControlSupervisor. فئات متتابعة بحسابات محددة باستخدام pandas وpython-pptx؛ لا تتصل بنموذج لغوي ولا تحتاج مفتاح API. مساعد التنسيق في `python_engine/base_pipeline.py` معاد استخدامه من مهارة infection-control-reports المحلية، مع محول مستقل لنموذج Tracker.

لا تحتاج النسخة الحالية استضافة Python: يشغّل `public/report-worker.js` المحرك عبر Pyodide داخل Web Worker. يتطلب التحميل الأول الإنترنت لتنزيل بيئة التشغيل من jsDelivr والمكتبات من PyPI. يبقى الملف الخام على الجهاز؛ تُرسل نتائج المعاينة إلى قاعدة الموقع عند الحفظ فقط. لا توجد خدمة Python سحابية أو مهام خلفية.

## قواعد البيانات والحساب

- IPCCC وRPP: قياس ربعي؛ نظافة اليدين: متوسط 3 أشهر مكتملة لكل ربع.
- PHC ICA: نصف سنوي؛ لا يوزع على الأرباع. السنوي يتطلب النصفين.
- متوسط الفترة للمنشأة يتطلب اكتمال جميع فتراتها. الناقص ليس صفرًا.
- النسب الجاهزة تُلخّص بمتوسطات بسيطة غير موزونة بفرص الرصد؛ لا تُخترع أعداد بسط أو مقام.
- التغير بالنقاط المئوية يقارن أول وآخر فترة لنفس المنشآت المكتملة خلال جميع الفترات المختارة.
- التكرار المتطابق يُستبعد، والمتعارض يوقف التحليل. تُعرض الأسماء غير المطابقة للمراجعة.
- يدعم نموذج Tracker بأوراق IPCCC وRPP وHospital/PHC H.H Monthly وPHC ICA Self-Assessment، وليس كل تصميم Excel. احفظ نتائج صيغ Excel قبل الرفع؛ pandas لا يعيد حسابها.
- الأرقام 0–9. لا تُضاف حدود معيارية أو أسباب سريرية مفترضة.

## تشغيل الواجهة

Node.js >=22.13:

```sh
npm ci
npm run dev
```

React/Vinext وCloudflare D1. مكتبات الواجهة في package.json وpackage-lock.json؛ لا تثبت عبر pip. ترحيلات القاعدة في drizzle/. الاستضافة الأصلية تستخدم Sites وتسجيل الدخول الخاص بها. نشر الكود في GitHub لا ينشئ قاعدة بيانات أو ينقل البيانات أو يفعّل الاستضافة. يجب إعداد المصادقة والقاعدة عند استخدام استضافة أخرى.

## تشغيل Python محليًا

Python 3.11 أو أحدث:

```sh
python -m pip install -r requirements.txt
python report_generator.py Tracker.xlsx --scope H2 --year 2026 --output outputs/report.pptx
python report_generator.py Tracker.xlsx --scope compare:Q1,Q3,Q4 --program hh --output outputs/comparison.pptx
python -m streamlit run local_app.py
python -m unittest discover -s tests -v
```

استخدم --include-zero لاحتساب الأصفار الفعلية. مجلد outputs/ مستبعد من Git.

## التحقق

اختبارات حسابية للأرباع والنصفين والسنوي والمقارنات والناقص والصفر الحقيقي، وفحص وجود جداول ورسوم أصلية في PPTX. التحقق البنيوي لا يغني عن مراجعة العرض بصريًا في PowerPoint قبل الاعتماد الرسمي.
